# Brand assets (logos)

SuCAR logo and wordmark files.

> ⚠️ The current brand logo `Sucarcar.jpeg` lives at the parent folder
> (`/images/Sucarcar.jpeg`) and is referenced across the app and in
> `index.css` (`body::before`). **Do not move or rename it** — put *new*
> brand variants here instead, and reference them as `/images/brand/<file>`.

Recommended files:
- `sucar-logo.svg` — primary vector logo (preferred for crispness)
- `sucar-logo-light.svg` / `sucar-logo-dark.svg` — theme variants
- `sucar-mark.svg` — icon-only mark (favicons, app tiles)
- `sucar-wordmark.svg` — text wordmark

Never AI-generate or redraw the brand logo — only the design team supplies it.
