# Raster icons / favicons

Most UI icons are **inline SVG** in code (`frontend/src/components/icons/Icon.tsx`)
— prefer adding glyphs there, not image files.

Use this folder only for raster icon assets that can't be inline SVG:
- `favicon.ico`, `favicon-32.png`, `favicon-16.png`
- `apple-touch-icon.png` (180×180)
- `og-image.png` (1200×630, social share preview)
