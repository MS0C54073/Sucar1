# Illustrations & section imagery

Supporting photos/illustrations for landing sections (use-case cards, feature
imagery, testimonial backgrounds, etc.).

- Format: WebP/AVIF preferred; optimized JPG/PNG otherwise.
- Always set explicit `width`/`height` (or an `aspect-ratio` container) to avoid
  layout shift, and `loading="lazy"` for anything below the fold.
- Keep the grade consistent with the hero: bright, real cars + water, daylight.

Suggested names: `usecase-fleet.jpg`, `usecase-parents.jpg`, `review-bg.jpg`.
